Common commands (Makefile): `make lint` (runs tools/markdown-lint), `make test` (skills-check + docs-check + ticket-check), `make check`, `make ci`. Ticket workflow: `make ticket T=<id> F=<feature>` or `tools/ticket-bootstrap T=<id> F=<feature>`; `make ticket-verify` and `make ticket-ci`. Docs bootstrap tools: `tools/bootstrap-into`, `tools/pc-ticket`, `tools/pc-commit`. Formatting: `make fmt` is TODO (not defined yet).
