Project purpose: PezzosCode is a macOS-first CLI/docs template system for AI-assisted software development. It bootstraps projects with a structured docs workflow (context → PRD → features → tickets → execute) and tools to run ticket workflows with Codex. Scope: local CLI tooling + templates; no UI, no cloud, no multi-user, no Windows. Target user: a single developer/PO who wants one-command bootstrap and predictable AI execution. Product principles: simplicity/robustness, AI-first low setup, idempotent/recoverable runs. Primary docs entrypoints: docs/README.md, docs/00-context/*, docs/01-product/prd.md, docs/02-features/*, docs/03-logs/*, docs/04-process/*.
