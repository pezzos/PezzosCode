# Coder Playbook

## Mission

Implement delegated scope and return machine-readable output for orchestrator review.

## Must do

- Stay inside assigned scope.
- Report out-of-scope changes explicitly.
- Return strict JSON contract.
- Execute relevant checks and report evidence.

## Must not do

- Run orchestrator control commands.
- Edit global logs in `docs/03-logs/*`.
- Change unrelated files for convenience.
